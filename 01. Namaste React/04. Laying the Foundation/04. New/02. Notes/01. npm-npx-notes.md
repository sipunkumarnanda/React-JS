
# 📦 What is npm?

## Definition

**npm** stands for

> **Node Package Manager**

It is the official package manager for Node.js.

Its primary responsibilities are:

✅ Install packages

✅ Remove packages

✅ Update packages

✅ Manage dependencies

✅ Run scripts

---

## Example Commands

```bash
npm install
npm install parcel
npm uninstall parcel
npm update
npm run start
npm run build
```

---

## Think of npm like Google Play Store

Imagine your phone.

Google Play Store

* installs apps
* updates apps
* removes apps

Similarly,

npm

* installs packages
* updates packages
* removes packages

---

# ⚡ What is npx?

## Definition

**npx** is a

> **Package Executor**

Unlike npm,

its job is NOT to install packages.

Its job is

> Find an executable and run it.

---

Example

```bash
npx parcel index.html
```

means

> Find Parcel and execute it.

---

Another example

```bash
npx create-react-app myApp
```

means

> Download (if necessary) and execute Create React App.

---

# 🤔 Difference Between npm and npx

| npm                  | npx                                |
| -------------------- | ---------------------------------- |
| Installs packages    | Runs packages                      |
| Manages dependencies | Executes executables               |
| Reads package.json   | Looks for executable               |
| Used daily           | Mostly used for one-time execution |

# 🎯 Quick Revision (Interview Ready)

## 📦 npm

* Node Package Manager.
* Installs, removes, updates packages.
* Runs scripts from `package.json`.

---

## ⚡ npx

* Node Package Executor.
* Finds a package's executable and runs it.
* Can temporarily download a package if it's not installed locally.

---

## 🚀 Executable

* A program that the operating system can run.
* Examples: `node`, `npm`, `git`, `parcel`, `python`.

---

## 📄 package.json

* The configuration file of a Node.js project.
* Stores metadata, dependencies, and scripts.

---

## 📜 Scripts

* Named commands inside `package.json`.
* Run with `npm run <script-name>`.

---

## 🏃 `npm run start`

1. Opens `package.json`.
2. Looks inside `"scripts"`.
3. Finds `"start"`.
4. Executes the command (e.g., `parcel index.html`).

---

## ⚡ `npx parcel index.html`

1. Looks for the `parcel` executable in `node_modules/.bin`.
2. If found, runs it.
3. If not found, may temporarily download it and run it.
4. Passes `index.html` as an argument to Parcel.

---

# ⭐ Final One-Line Summary

> **`npm` manages packages and runs project scripts, `npx` executes package CLIs, `package.json` stores project configuration and scripts, scripts are named commands, and an executable is any program (like `parcel`, `node`, or `git`) that the operating system can run.**
